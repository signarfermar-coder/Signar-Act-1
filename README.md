# MapQuest Route Planner

This is a static HTML, CSS, and JavaScript web application that integrates the MapQuest Directions API.

## How to use

1. Create a MapQuest developer account at `https://developer.mapquest.com/`.
2. Generate an API key from the **Manage Keys** page.
3. Open `config.js`.
4. Replace `PASTE_YOUR_MAPQUEST_KEY_HERE` with your real key.
5. Open `index.html` in a browser.
6. Enter a starting location and a destination, then click **Get Route**.

## What the app shows

- Request inputs in a table
- API response summary in a table
- Step-by-step maneuvers in a table
- A route preview map image
- An execution log so you can document at least three runs

## Required screenshots

Run the application at least three times with different locations and take one screenshot after each successful execution.
